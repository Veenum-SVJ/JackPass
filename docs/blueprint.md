# **App Name**: JackPass

## Core Features:

- Advanced Question Search: Implement a comprehensive search function that includes filters for institution name, course name, faculty/department, year of exam, and semester, question type and keyword to make retrieving specific question papers quicker for the users.
- Interactive Question Viewer: Enable users to view past questions along with available answers and detailed explanations, with the option to toggle between showing and hiding answers. Also includes an easy navigation system.
- Easy Question Upload: Feature a persistent footer bar with an 'Upload Past Question' button that allows users to upload scanned files or capture new questions using their device camera, providing multiple options for contribution. Questions available only after admin approval.
- AI-Powered OCR Text Extraction with Auto-suggestions: Integrate OCR (Optical Character Recognition) technology as a tool using Google Vision API into the app. When users submit image uploads for past exam questions, this OCR feature will automatically extract the text, identify the institution and the names of courses mentioned in the question, and populate the available Institution and Course dropdown options based on the data detected. This aims to greatly simplify and speed up the uploading process by eliminating manual data entry, as well as prevent students from adding records from unapproved institutions.
- Related Questions: Show a list of question papers that may be relevant to the user's current paper of interest.

## Style Guidelines:

- Primary color: Deep sky blue (#3498DB) to create a clean and professional look that reflects the educational context of the app.
- Background color: Light gray (#ECF0F1) to reduce eye strain and provide a neutral backdrop for content.
- Accent color: Sunflower yellow (#F1C40F) to highlight important elements and CTAs, adding a touch of warmth and clarity.
- Body and headline font: 'Inter' (sans-serif) for clear readability on both mobile and desktop.
- Code font: 'Source Code Pro' for displaying any code snippets.
- Use consistent and professional icons from a library like FontAwesome to enhance usability and visual appeal.
- Fixed search bar and footer for continuous access. Card-based layout for question listings for improved content scanning and user experience.
